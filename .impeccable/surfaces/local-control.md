# Local Control

Mode: Operate. Build path: code-led for this precisely specified operating UI.
Audience: an owner controlling the television from a phone on the home LAN.
Success: open the last remote, send a supported command, leave no stuck press.
First viewport: device selector, connection state and recognizable controls.
Secondary path: Devices, Activities, Settings. No onboarding in daily control.
Signature interaction: a held control stays visibly pressed only for its lease;
release and connection loss both end transmission.
Risk: Bluetooth and fresh initialization must not look verified before testing.
