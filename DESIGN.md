# Harmony Hub Control Design

The user-approved remote-first plan fixes the direction: familiar consumer
remote controls, quiet operating surfaces, four destinations, no dashboard.
The Impeccable direction exercise is subordinate to that explicit brief.

Use system sans-serif, 16px body text, compact 22px page headings and zero
letter spacing. White and charcoal surfaces support both daytime setup and
dim-room viewing. Green indicates the active destination or connection;
red is reserved for destructive commands and errors. Neutral controls remain
distinct from both. No gradients, decorative backgrounds or marketing copy.

Remote controls have stable 52px minimum targets, a directional pad, separated
volume/channel pairs and playback controls. Unsupported commands are omitted.
The remote is an unframed tool, not a dashboard card. Extra commands appear in
a searchable drawer. Lucide symbols carry recognizable commands with accessible
names and tooltips. Bottom navigation on phones becomes a narrow desktop rail.

Devices and activities use unframed lists and focused editors. Settings group
ownership, integration, backup and recovery controls; advanced details stay
collapsed. Empty, pending, disconnected, busy and failed states name the actual
condition without pretending that an IR target responded.

Honor reduced motion. Focus rings remain visible. Pointer and keyboard holds
release on cancellation, navigation, hidden tabs and lost connectivity.
